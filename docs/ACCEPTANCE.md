合计 147 项自动化检查。详细 API 和数据库结果见 `artifacts/verification.json`，其余检查可按 README 命令复验。前端交互、契约、构建日志分别保留在 `artifacts/frontend-v05-run.log`、`contract-v05-run.log` 与 `build-v05-run.log`。

数据库引擎实测 `server_version = 18.3`，运行在 PGlite 0.5.8。Npgsql 通过 TCP 适配器连接该引擎；EF 迁移实际建立业务表，C# 种子实际加载样本，API 实际运行。验证器为适配器预建空 EF 迁移记录表，避免首次探测不存在表的协议恢复问题。

验证适配器允许 16 个连接，避免前一个 TCP 连接尚未关闭时拒绝下一次 Npgsql 握手；SQL 仍由适配器串行排队执行。首轮较小数据包验证成功，补充资料后的快照导出曾遇连接关闭竞态，修正该测试配置后重新执行完整验证。

没有用内存数组替代后端排名、百分比或年度求和。预览里的这些结果来自执行后的 API 响应。真实档案的筛选和分页也在前端执行，不计算跨范围邀请人数总和；自由问题不在快照中时明确提示需要运行本地服务。
